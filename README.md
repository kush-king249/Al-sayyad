# Al-Sayyad - أداة مكافحة الفيروسات المتقدمة

**Al-Sayyad** هي أداة متقدمة لمكافحة الفيروسات مصممة لتوفير حماية شاملة ضد مجموعة واسعة من التهديدات السيبرانية. تجمع الأداة بين تقنيات الكشف القائمة على التوقيعات والكشف السلوكي والاستدلالي، بالإضافة إلى المراقبة في الوقت الفعلي لنظام الملفات والعمليات والاتصالات الشبكية. تم تطويرها باستخدام لغة Python وتوفر واجهة مستخدم رسومية احترافية وتفاعلية وسهلة الاستخدام باللغة العربية.

**by Hassan Mohamed Hassan Ahmed**

## الميزات الرئيسية

*   **حماية في الوقت الفعلي:** مراقبة مستمرة لنظام الملفات للكشف عن الأنشطة المشبوهة. 
*   **مسح متعدد التقنيات:** يجمع بين:
    *   **المسح القائم على التوقيعات:** الكشف عن البرامج الضارة المعروفة باستخدام قاعدة بيانات التجزئة (Hashes).
    *   **المسح السلوكي والاستدلالي:** تحليل سلوك الملفات والعمليات للكشف عن التهديدات الجديدة وغير المعروفة.
*   **واجهة مستخدم رسومية احترافية (GUI):** لوحة تحكم تفاعلية وسهلة الاستخدام لعرض حالة الحماية، بدء المسح، وإدارة التهديدات.
*   **إدارة التهديدات:** حجر الملفات المشبوهة، واستعادتها، أو حذفها بشكل دائم.
*   **تحديثات قاعدة البيانات:** آلية لتحديث قاعدة بيانات التوقيعات لضمان الحماية من أحدث التهديدات.
*   **إحصائيات وتقارير:** عرض رسوم بيانية وإحصائيات حول نشاط التهديدات وعمليات المسح.

## الهيكلية المعمارية

تتبع Al-Sayyad هيكلية معيارية مقسمة إلى مكونات رئيسية لضمان الكفاءة وسهولة الصيانة:

*   **`src/core/`**: يحتوي على المنطق الأساسي للأداة مثل محرك المسح (`scanner.py`)، مدير قاعدة البيانات (`database_manager.py`)، مراقب الوقت الفعلي (`real_time_monitor.py`)، ومحدث التوقيعات (`updater.py`).
*   **`src/gui/`**: يحتوي على مكونات الواجهة الرسومية (`main_window.py`, `ui_elements.py`).
*   **`src/utils/`**: يحتوي على وظائف مساعدة مثل عمليات الملفات (`file_operations.py`) ومحلل النظام (`system_analyzer.py`).
*   **`data/`**: لتخزين قاعدة بيانات التوقيعات (`signatures.db`) والملفات المحجورة (`quarantine/`).
*   **`tests/`**: لاختبارات الوحدة للمكونات المختلفة.

## المتطلبات

تتطلب الأداة بيئة Python 3.x والمكتبات التالية:

*   `PyQt5`
*   `watchdog`
*   `pefile` (لنظام Windows)
*   `psutil`
*   `SQLAlchemy`
*   `requests`
*   `pyqtgraph`
*   `matplotlib`

يمكن تثبيت هذه المكتبات باستخدام `pip`:

```bash
pip install -r requirements.txt
```

## التثبيت والتشغيل

لإعداد وتشغيل Al-Sayyad على جهازك، اتبع الخطوات التالية:

1.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/kush-king249/Al-Sayyad.git
    cd Al-Sayyad
    ```

2.  **تثبيت المتطلبات:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **تشغيل الأداة:**
    ```bash
    python src/main.py
    ```

    ستظهر شاشة بداية ثم الواجهة الرسومية الرئيسية للأداة.

## الاستخدام

بعد تشغيل الأداة، ستظهر لوحة التحكم الرئيسية التي توفر نظرة عامة على حالة الحماية والإجراءات المتاحة:

*   **شاشة الحالة الرئيسية:** تعرض ما إذا كان النظام 

محميًا أم لا، مع مؤشر بصري واضح.
*   **الإجراءات السريعة:** أزرار لـ "مسح سريع"، "مسح كامل"، "تحديث"، و "الحجر الصحي".
*   **مراقبة التهديدات:** رسم بياني يوضح نشاط التهديدات على مدار الوقت.
*   **الإشعارات:** لوحة تعرض الإشعارات الأخيرة حول التهديدات المكتشفة وعمليات المسح.

### كيفية إجراء مسح:

1.  **مسح سريع:** انقر على زر "مسح سريع" لإجراء مسح للمجلدات الشائعة (سطح المكتب، التنزيلات، المستندات).
2.  **مسح كامل:** انقر على زر "مسح كامل" ثم اختر المجلد الذي ترغب في مسحه بالكامل.
3.  **مسح مجلد مخصص:** من قائمة "ملف"، اختر "مسح مجلد..." لتحديد أي مجلد آخر للمسح.

### الحجر الصحي:

عند اكتشاف تهديد، سيتم نقله تلقائيًا إلى مجلد الحجر الصحي. يمكنك الوصول إلى "الحجر الصحي" من الأزرار السريعة أو من قائمة "أدوات" لإدارة الملفات المحجورة (استعادة أو حذف).

### التحديثات:

انقر على زر "تحديث" للتحقق من وجود تحديثات جديدة لقاعدة بيانات التوقيعات وتثبيتها.

## التوثيق والاختبار

*   **توثيق الكود:** تم توثيق جميع الدوال والفئات باستخدام `docstrings` لسهولة الفهم والصيانة.
*   **اختبارات الوحدة:** يتضمن المشروع اختبارات وحدة للمكونات الأساسية (محرك المسح، عمليات الملفات، مدير قاعدة البيانات) لضمان عملها بشكل صحيح.
    يمكن تشغيل الاختبارات من مجلد `tests/`:
    ```bash
    python -m unittest discover tests
    ```

## خطة التطوير المستقبلية

*   **تحسين الكشف السلوكي:** دمج تقنيات تعلم الآلة لتحسين قدرات الكشف عن التهديدات غير المعروفة.
*   **دعم متعدد المنصات:** توسيع الدعم ليشمل أنظمة تشغيل أخرى مثل Linux و macOS.
*   **خادم تحديثات حقيقي:** تطوير خادم تحديثات مركزي لتوفير تحديثات توقيعات منتظمة.
*   **حماية الويب:** إضافة ميزات لحماية التصفح من المواقع الضارة.
*   **جدار حماية:** دمج جدار حماية بسيط لمراقبة حركة مرور الشبكة.
